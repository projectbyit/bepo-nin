# Bepo Restaurant Konoba Nin

English marketing landing page for **Bepo Restaurant Konoba Nin**.

## Stack

- Next.js (App Router) + TypeScript + Tailwind CSS v4
- Deploy target: Vercel
- Source: GitHub

## Sections

1. Navigation
2. Hero
3. About
4. Gallery
5. Info & Map
6. Contact form
7. Footer

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Brand notes

- Palette from Figma *Bepo Social Media 2026* (beige, gold, light neutrals)
- Legacy colors excluded: `#674545`, `#463030`
- Fonts: WindSong + Sorts Mill Goudy

## Contact form

`POST /api/contact` currently logs submissions. Connect Resend or Formspree before production email delivery.
